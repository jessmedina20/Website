# Product

This project is a dependency-free, multi-page academic portfolio for a PhD candidate. It helps prospective collaborators, hiring committees, students, and scholarly peers quickly understand the researcher’s agenda, publications, teaching, experience, and contact details.

## Core surfaces

- Home: identity, research thesis, highlights, selected publications, and news.
- Research: a coherent research program with detailed project narratives.
- Publications: year-grouped record with client-side type filters and BibTeX.
- Teaching: philosophy, roles, mentoring, and reusable materials.
- CV: readable web CV, downloadable PDF, and print support.
- Contact: affiliation, direct email, office, and scholarly profiles.

## Constraints

Static HTML, CSS, and lightweight JavaScript only. No build step or backend. All internal paths remain relative for GitHub Pages. Personal facts, links, portrait, and the CV PDF are explicit placeholders until supplied by the site owner.
